# 远程控制：中继服务器与测试指南

## 1. 中继服务器是什么？

可以理解成一个很小的网站后台，但它不提供网页：

- **网页**（`index.html`、`remote.html`）仍然放在 GitHub Pages 上。
- **中继服务器**只负责转发消息。现场手机和远程浏览器都主动连到它，它在两边之间传递指令，比如"开始某个球路"和"停止"。

需要中继的原因是双方不能直接互连：现场手机在家里的路由器后面，外网连不进来。所以两边都向外连到一个公网上的中间点。

正式使用时需要满足三点：

- 一台公网能访问的机器，比如便宜的云服务器（VPS），或者其他能长期运行 Node.js 的服务。
- 一个域名和 HTTPS 证书。页面只接受 `wss://` 地址，用 Caddy 做反向代理时证书是自动申请的。
- 只需要很少的资源，最小规格的机器就够用。

## 2. 在局域网内测试：最简单的是 USB 方案

手机上的 Web Bluetooth 要求页面通过 HTTPS 打开，或者地址是 `localhost`。用局域网 IP 打开普通的 `http://` 页面，蓝牙用不了。

可以用 Android Chrome 的端口转发，让手机把电脑上的服务当作自己的 `localhost` 访问。这样不需要证书，也不需要改代码：

1. 在电脑上的仓库目录里启动网页服务：
   ```bash
   python3 -m http.server 8000 --bind 127.0.0.1
   ```
2. 在电脑上启动中继：
   ```bash
   cd server && npm ci
   ALLOWED_ORIGINS=http://localhost:8000 PORT=8787 npm start
   ```
3. 准备手机：
   - 打开"开发者选项 → USB 调试"，用 USB 线连接电脑。
   - 在电脑的 Chrome 里打开 `chrome://inspect/#devices`，点 **Port forwarding**。
   - 添加 `8000 → localhost:8000` 和 `8787 → localhost:8787` 两条，并勾选启用。
4. 在手机 Chrome 里操作：
   - 打开 `http://localhost:8000/index.html`，连接发球机。
   - 菜单 → 远程控制，中继地址填 `ws://localhost:8787/ws`，然后开启会话。
5. 把邀请链接发到电脑上，比如通过微信。在电脑浏览器里打开它，这台电脑就充当"远程端"。

这个方案走的是 USB，不是真的远程，但整套流程和真机行为都能完整测试。

## 3. 想用真实网络测试，又暂时没有服务器

可以用临时隧道，比如 Cloudflare 的 `cloudflared`，它会给本机服务生成一个临时的 HTTPS 地址：

```bash
cloudflared tunnel --url http://localhost:8787
# 会输出类似 https://xxxx.trycloudflare.com 的地址
```

- 先把代码推送到 GitHub，让网页从 GitHub Pages 加载。
- 中继启动时用 `ALLOWED_ORIGINS=https://wenguang1111.github.io`。
- 手机打开 `https://wenguang1111.github.io/nova/`，中继地址填 `wss://xxxx.trycloudflare.com/ws`。
- 远程端可以用另一台设备，通过移动数据打开邀请链接。

这个地址每次启动都会变，只适合测试。

## 4. 真机要测什么

重点是确认停止是否可靠。建议先用低速、少次数的球路，人站在发球机侧后方，手放在电源开关上：

| 测试 | 操作 | 期望结果 |
|---|---|---|
| 基本流程 | 远程请求 → 现场点允许 | 按设定的次数或时间发球后自动停止 |
| 远程停止 | 运行中远程点停止 | 立即停止 |
| 现场停止 | 运行中在现场手机上点停止 | 立即停止，远程端显示"已停止" |
| 远程断网 | 运行中关闭远程页面或断网 | 现场手机自动停止发球机 |
| 中继断开 | 运行中在电脑上按 Ctrl+C 停掉中继 | 现场手机自动停止 |
| 现场切后台 | 运行中现场手机切到其他应用 | 会话结束，发球机停止 |
| **关键：停止送不到** | 运行中在现场手机上直接关蓝牙或开飞行模式 | **观察发球机会不会自己停下来**。这一项决定能不能放心让远程控制长时间运行 |
| 锁屏 | 运行中按电源键锁屏 | 记录发球机是否停止 |

最后两项的结果请记录下来。如果发球机在蓝牙断开后会一直发球，后续就需要考虑更保守的做法，比如把单次训练的时长和次数上限调得更低。
