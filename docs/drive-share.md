# 共享球路到 Google Drive

编辑器里的“共享”按钮把当前球路（CSV，与“导出”格式相同，可直接导入）发给一个 Google Apps Script 网页应用，由它写入你的 Drive 文件夹。用户的浏览器里只有脚本地址，没有文件夹地址或 ID；文件夹 ID 只保存在脚本属性里。

## 部署（一次性）

1. 打开 <https://script.google.com> → 新建项目，把 `apps-script/Code.gs` 全部内容粘贴进去。
2. 左侧“项目设置” → “脚本属性” → 添加：`FOLDER_ID` = 目标文件夹 URL 中 `folders/` 后面那一段。
3. “部署” → “新建部署” → 类型“网页应用”：
   - 执行身份：**我**
   - 有权访问：**任何人**
4. 授权（会请求 Drive 权限），复制 `https://script.google.com/macros/s/…/exec` 地址。
5. 把该地址填入 `js/cloud.js` 的 `DRIVE_UPLOAD_URL`，提交并推送。

修改 `Code.gs` 后必须“部署 → 管理部署 → 编辑 → 新版本”，地址不变。

## 防滥用

脚本地址在前端源码里是公开的，所以服务端做了限制：请求体上限、名称白名单、每行严格数字校验（不会产生表格公式）、每天最多 200 个文件。文件夹本身不要设为公开；只有你能看到上传内容。
