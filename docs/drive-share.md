# 共享球路（Google Drive）

## 功能
- **共享**（编辑器底部按钮）：用户填写名字和简短描述（默认为球路名称），当前球路以 CSV（与“导出”格式相同）上传到你的 Drive 文件夹。
- **下载球路**（主菜单）：用户输入密码后看到文件夹里所有已共享的球路，勾选后导入到自定义 A、B 或 C。只追加，不覆盖现有球路。

两者都经过一个 Google Apps Script 网页应用（`apps-script/Code.gs`）。用户的浏览器里只有脚本地址，没有文件夹地址或 ID；文件夹 ID 和下载密码只保存在脚本属性里，不会出现在这个公开仓库里。

## 部署（一次性）

1. 打开 <https://script.google.com> → 新建项目，把 `apps-script/Code.gs` 全部内容粘贴进去。
2. 左侧“项目设置 → 脚本属性”添加两项：
   - `FOLDER_ID`：目标文件夹 URL 中 `folders/` 后面那一段。
   - `DOWNLOAD_PASSWORD`：下载列表用的密码。
3. “部署 → 新建部署” → 类型“网页应用”：执行身份 **我**，有权访问 **任何人**。
4. 授权（会请求 Drive 权限），复制 `https://script.google.com/macros/s/…/exec` 地址。
5. 把该地址填入 `js/cloud.js` 的 `DRIVE_URL`，提交并推送。

修改 `Code.gs` 后必须“部署 → 管理部署 → 编辑 → 新版本”，地址不变。改密码只需改脚本属性，立即生效，不用重新部署。

## 安全说明

- 脚本地址在前端源码里是公开的，任何人都能向它发请求，所以服务端做了限制：
  - 上传：请求体大小、名称白名单、每行严格数字校验（不会产生表格公式）、每天最多 200 个文件。
  - 下载：必须提供密码；只能读取该文件夹内、带有共享说明的文件；每次最多 30 个。
- 密码只在服务端比对。没有用户身份可区分，所以密码错误次数是**全局**按小时统计的：每小时累计错误 30 次后，所有人（包括正确密码）都会被拒绝到下一个整点。
- 简单密码（例如纯数字 8 位）可以被猜到，限流只能减慢，不能阻止。密码泄露后任何人都能下载和导入，换密码即可。
- 列表只显示通过本网页上传（带“Drill:”说明）的文件；手动放进文件夹的文件不会出现。
- 列表最多显示最新 300 个。
- 下载者看到的名字和描述是上传者随意填写的，页面只当文本显示，不会执行。
